# Shichao Li

Associate Professor with the **School of Information and Communication / Guangxi (Wireless Broadband Communication and Signal Processing) Key Laboratory, Guilin University of Electronic Technology** (Guilin, China); the parse biographies consistently report email `shichaoli@guet.edu.cn`. PhD in communication and information systems, Beijing Jiaotong University, 2019 (per the author biographies). Research interests include mobile edge computing, vehicular networks, and wireless resource allocation.

Co-authored 4 sources in this wiki across two-hop air-ground MEC, vehicular edge computing, and UAV-mounted IRS data collection:

- [[zhao-2026-uav-irs-data-collection]] - UAV-mounted IRS sensor collection with joint hover placement and reflecting-element selection.
- [[li-2024-twohop-iort-packet-scheduling]] — two-hop packet scheduling + resource allocation + UAV trajectory (MADDPG-APER) for IoRT (lead author).
- [[li-2025-twohop-airground-drl-offloading]] — two-hop partial task offloading + resource allocation (JPTORAUTD: MADDPG-IPER + NV-IPPO) (lead author).
- [[li-2024-airground-vec-offloading]] — joint computation offloading + multidimensional resource allocation in an air-ground integrated VEC network (HAP + UAVs + RSU); JCESRA (BCD + matching + coalition game + CVX + SCA + knapsack/DP) (lead author).
