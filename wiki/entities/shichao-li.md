# Shichao Li

Associate Professor with the **School of Information and Communication / Guangxi (Wireless Broadband Communication and Signal Processing) Key Laboratory, Guilin University of Electronic Technology** (Guilin, China); email `shichaoli@guet.edu.cn` (consistent across both sources). PhD in communication and information systems, Beijing Jiaotong University, 2019 (per the author biography in the parse). Research interests include mobile edge computing, vehicular networks, and wireless resource allocation.

Co-authored 3 sources in this wiki — two on two-hop air-ground integrated MEC for the Internet of Remote Things (IoRT), and one on air-ground integrated vehicular edge computing:

- [[li-2024-twohop-iort-packet-scheduling]] — two-hop packet scheduling + resource allocation + UAV trajectory (MADDPG-APER) for IoRT (lead author).
- [[li-2025-twohop-airground-drl-offloading]] — two-hop partial task offloading + resource allocation (JPTORAUTD: MADDPG-IPER + NV-IPPO) (lead author).
- [[li-2024-airground-vec-offloading]] — joint computation offloading + multidimensional resource allocation in an air-ground integrated VEC network (HAP + UAVs + RSU); JCESRA (BCD + matching + coalition game + CVX + SCA + knapsack/DP) (lead author).
