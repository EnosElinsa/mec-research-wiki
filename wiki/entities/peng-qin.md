# Peng Qin

IEEE Member. Co-authored 3 sources in this wiki, all in the aerial/SAGIN edge-computing line:

- [[qin-2025-bcuav-masac]] — cooperative UAV trajectory + resource allocation in blockchain-enabled secure aerial edge computing (MASAC).
- [[qin-2025-matd3-noma-queue-sagin]] — NOMA-enabled queue-aware task offloading and AAV 3D trajectory planning for SAGIN (MATD3).
