# Edge Intelligent Vehicle

An edge intelligent vehicle (EIV) is a mobile ground node that combines UAV logistics with local edge processing. It can launch, recover, and recharge UAVs while receiving and processing the data they collect, creating a collect-in-the-air/process-on-the-ground architecture.

[[huang-2026-slim-eiv-uav-fleet]] places EIVs along a linear mission route so they partition deadline-constrained tasks into independent UAV segments. The evaluation models homogeneous, pre-deployed EIVs with zero setup time, so physical relocation, compute queues, failures, and deployment delay remain outside the demonstrated result.
