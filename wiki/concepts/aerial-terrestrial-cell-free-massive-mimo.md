# Aerial-Terrestrial Cell-Free Massive MIMO

A user-centric architecture in which distributed UAV-mounted flying access points jointly serve ground users over shared time-frequency resources under central coordination, without fixed cell boundaries. A user can be associated with multiple FAPs, reducing handover dependence and improving edge coverage, while pilot contamination, fronthaul load, distributed power, and moving access-point geometry become coupled design concerns.

[[shah-2026-cellfree-mimo-fap-control]] uses a 3GPP Option 8 split: UAVs perform RF-side functions and a central processor handles baseband cooperation. This simplifies the source's model but implies substantial I/Q fronthaul capacity and power overhead that it does not optimize.
