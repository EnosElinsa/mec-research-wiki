# Matern Hard-Core Base-Station Deployment

A repulsive point-process model that enforces a minimum distance between terrestrial base stations, avoiding the unrealistically close pairs allowed by an independent Poisson process. [[ren-2026-distributed-uav-los]] uses a finite Matérn hard-core process and its retention probability to derive candidate-BS distance distributions for urban aerial-user association and outage analysis.
