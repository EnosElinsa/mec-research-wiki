# Six-Dimensional Aerial Rotatable Antenna Array

A UAV-mounted rigid array controlled through the UAV's three-dimensional position and the array's three-axis orientation. Translation changes path loss and service geometry; rotation changes local arrival angles and array steering without moving individual antenna elements.

[[wang-2026-6dara-cellfree]] coordinates this six-dimensional geometry at frame scale with user association, while receive combining adapts per slot. It differs from [[movable-antenna]], where radiating elements move within a local region.
