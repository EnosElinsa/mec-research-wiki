# Fly-While-Communication

A UAV operating mode in which wireless service continues along flight segments instead of being restricted to stationary hover periods. Path geometry and velocity then jointly determine both travel time and communication opportunity.

[[guo-2026-uav-wsn-completion-time]] applies this mode to wireless-powered sensor collection, including segments whose overlapping service regions cover adjacent nodes. It contrasts with [[successive-hover-and-fly-trajectory]], where communication is concentrated at hover points.
